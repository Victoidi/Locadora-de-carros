# Pasta `static/css`

Contem os estilos da interface web.

## Arquivos

- `style.css`: folha de estilo principal da aplicacao.
  - Define visual de formularios, tabelas, layout e elementos comuns.
  - Suporta as telas de login, dashboard, clientes, inventario e pagamentos.

## Diretrizes

- Manter padrao visual consistente com as telas em `templates/`.
- Organizar regras por secao (layout, componentes, utilitarios) para facilitar manutencao.
