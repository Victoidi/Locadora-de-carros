# Pasta `static`

Arquivos estaticos servidos diretamente pelo Flask.

## Subpastas

- `css/`: folhas de estilo da interface.
- `images/`: imagens e ilustracoes usadas no layout.

## Responsabilidades

- Centralizar estilos globais da aplicacao.
- Manter ativos visuais reutilizaveis em paginas diferentes.

## Recomendacoes

- Minificar e otimizar arquivos estaticos em pipeline de producao quando o projeto evoluir.
- Evitar duplicacao de assets para reduzir tamanho do repositorio.
