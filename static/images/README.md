Ativos visuais utilizados pela interface da aplicacao.

- `greenride-logo.png`: logo principal exibida na interface.

## Diretrizes

- Preferir SVG para icones e ilustracoes quando possivel.
- Manter nomes de arquivos descritivos e consistentes.
